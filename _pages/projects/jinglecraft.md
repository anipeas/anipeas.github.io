> ### JINGLECRAFT - MACHINE LEARNING IN MUSIC (2022)

- <small> Conducted comprehensive analysis of machine learning algorithms and data visualization techniques for music genre classification and mood prediction. </small>
- <small> Leveraged multiple data sources including the Million Song Dataset, GTZAN, and Spotify API to create a robust training dataset. The analysis incorporated both spectral features (mel-spectrogram visualization shown below) and metadata features to capture comprehensive musical characteristics. </small>
